# Investigation workflow walkthroughs

Open [index.html](index.html) in a browser. No installation, server, credentials, or network access is required.

This throwaway planning simulation explores the question in [Validate end-to-end investigation workflows across case types](https://github.com/TheDarkSkyXD/OSINT-AI-Spider/issues/19). It does not run the production application or real investigations.

The October 15 update applies the shared grayscale dark theme. Original source-page content retains its colors. The numbered steps and free exploration behavior are unchanged.

Choose a Case type in the sidebar and press each numbered step. Every walkthrough uses the same state model and different fictional material. Free exploration controls let you try invalid action orders, interruptions, offline work, and model changes. Reset clears only the current in-memory walkthrough.

The six walkthroughs cover missing-person, criminal, cyber, financial, GitHub, and general research Cases. Their difficult cases cover contradictory evidence, timestamp corrections, active-target scope, common-name identity matches, source instructions, and partial captures.

Switch between Web and Electron to inspect the same workflow. Mobile mode demonstrates a proposed subset and a way to continue complex graph editing and Report composition on web. It is an experience sketch, not proof of native platform execution or human usability acceptance.

The user [approved this shared workflow](https://github.com/TheDarkSkyXD/OSINT-AI-Spider/issues/19#issuecomment-6191360179) on October 15, 2026, including unresolved material and human review. Real client behavior and integrations still require implementation acceptance tests.
